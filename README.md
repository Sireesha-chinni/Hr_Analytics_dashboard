# HR Analytics Dashboard with Attrition Prediction

## 👋 What's This Project About?

Every year, companies lose millions trying to replace employees who quietly decided to leave — often for reasons that could have been spotted months earlier in the data.

This project takes a raw, messy HR dataset and turns it into something useful: a clean analytical foundation, a visual dashboard HR teams can actually use, and a machine learning model that flags employees at risk of leaving before they hand in their resignation.

It's a full-stack data analytics project — the kind you'd actually do on the job — covering every step from dirty data to boardroom-ready insights.

---

## 🧭 What I Did (Project Phases)


```
Raw Messy Data  →  Data Cleaning  →  EDA  →  Dashboard  →  ML Model  →  Insights
```

**Phase 1 — Data Cleaning**
The raw dataset came with real-world mess: missing values, duplicates, typos in categories, outliers, wrong data types, and logical errors. Cleaned it all systematically before touching any analysis.

**Phase 2 — Exploratory Data Analysis**
Dug into the data to understand who's leaving, from which departments, at what income levels, and why. Lots of visualizations, pattern spotting, and correlation checks.

**Phase 3 — Dashboard**
Built an interactive HR dashboard with department filters, attrition KPIs, and drill-down charts — designed for someone in HR who doesn't write code.

**Phase 4 — Attrition Prediction**
Trained classification models to predict which employees are most likely to leave, evaluated them properly, and identified the top factors driving attrition.
